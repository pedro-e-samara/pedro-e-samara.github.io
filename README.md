# Pedro & Samara

Site de presentes de casamento e construção do novo lar.

**Celebração:** 21 de outubro de 2026.

**Site:** https://rodrigocostaaa60.github.io/pedro-e-samara/

## Publicação

O GitHub Actions publica automaticamente a pasta `site/` no GitHub Pages quando
ela é atualizada na branch `codex/github-pages`. Também é possível executar o
workflow **Publicar Pedro e Samara** manualmente na aba Actions.

O projeto usa HTML, CSS e JavaScript, com um backend independente em Google Apps
Script. O endpoint público está em `site/registry-config.js`; ele não é uma senha.
A planilha, as credenciais dos convidados, o código administrativo, os backups e
os testes não fazem parte deste repositório.

O backend deve autorizar a origem exata `https://rodrigocostaaa60.github.io`.
Não é necessário domínio próprio nem servidor contratado.
